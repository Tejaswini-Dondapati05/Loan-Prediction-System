Loan Prediction System

Project Overview

Developed an end-to-end Machine Learning-based Loan Prediction System using Python, Streamlit, and FastAPI to predict loan approval status based on applicant details.

Technologies Used

- Python
- Machine Learning
- Pandas and NumPy
- Scikit-learn
- Streamlit
- FastAPI
- REST API

Key Features

- Data preprocessing and feature engineering
- Machine Learning model training and prediction
- Interactive Streamlit user interface
- FastAPI-based REST API integration
- Automated loan approval prediction

How to Run

1. Install dependencies:
   "pip install -r requirements.txt"
2. Run the Streamlit application:
   "streamlit run loan_str.py"
3. Run the FastAPI server:
   "uvicorn loan.py:app --reload"

Project Goal

To simplify loan approval prediction through Machine Learning and provide an interactive application with API-based integration.
